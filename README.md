# 流放之路 2 · 做装模拟器

基于 0.5 版本游戏数据（poe2db / POE2_HTC）的武器做装模拟器，中文界面，本地运行，无需安装。

## 启动

双击 **`启动做装模拟器.bat`** —— 会以独立应用窗口（Edge/Chrome 应用模式，无地址栏）打开。
也可以直接双击 `app/index.html` 用任意浏览器打开。

## 功能

- **选武器 → 选基底**：9 类武器（弓 / 战矛 / 战弩 / 节杖 / 单手锤 / 双手锤 / 长杖 / 法杖 / 权杖），271 个基底（含符文熔铸 Runeforged / 符文师匠 Runemastered 系列），中英文名与基础属性。
- **完整做装通货**：蜕变 / 增幅 / 富豪 / 点金 / 崇高 / 神圣（重掷词缀数值）/ 混沌 / 破溃宝珠（分裂锁定词缀，免疫剥离与混沌删除）/ 辛格拉的发辫（预示下一个通货效果，可自由应用或放弃，与游戏一致：修改物品才会解除预示）/ 剥离 / 精华（21 种 × 4 级）/ 亵渎通货，全部支持 普通 / 高级 / 完美 分档（高档位只 roll 档位需求 ≥35 / ≥50 的词缀）。
- **全部游戏原图标**：316 张 poe2db 游戏原画 —— 12 种通货、13 种预兆、21 种精华、271 个武器基底插画（本地打包，离线可用；个别 CDN 缺失的素材自动回退）。运行 `python tools/fetch_icons.py` 可重新抓取/补齐。
- **13 种预兆**：升华（限前缀/后缀/额外词缀）、剥离（限前缀/后缀/光之预兆必删亵渎）、晶化、死灵、黑血/领主/君主（限定库尔加尔 / 阿玛纳姆 / 乌拉曼首领池）。
- **消耗统计**：按实际使用数量逐通货计数（如 混沌石×12、剥离石×3），不再做崇高石换算。
- **真实概率引擎**：(词缀 × 档位) 成对加权抽取，与 POE2_HTC 引擎一致 —— 同族互斥、同 ID 互斥、物品等级门控、通货档位下限，右侧面板实时显示下一次操作的完整结果分布（解析概率，非抽样）。
- **武器数值面板**：物理 / 元素 DPS、攻速、暴击实时计算；物品卡片风格贴近游戏内 tooltip。
- **成本与日志**：以崇高石为单位的累计成本（种子估值），逐步日志，支持撤销 / 重置。
- **会话保存**：刷新或关闭后自动恢复做装进度。

## 目录结构

```
启动做装模拟器.bat     启动器
app/                   前端应用（纯静态，无依赖）
  index.html / style.css / app.js / engine.js / stats.js / i18n_mods.js / data.js
data/
  bases.json           基底名录（中英文、属性，poe2db 提取）
  mods.json 等         词缀 / 通货 / 预兆 / 精华 / 价格原始数据
tools/
  build_data.py        重新打包 app/data.js
  check_i18n.py        词缀翻译覆盖率校验
  engine.test.js       引擎单元测试（node tools/engine.test.js）
```

## 数据更新

上游（poe2db / POE2_HTC）更新后：替换根目录的 JSON → `python tools/build_data.py` 重新打包即可；如新增词缀文本，往 `app/i18n_mods.js` 补译并用 `python tools/check_i18n.py` 校验覆盖率。

## 已知简化（与游戏的差异）

- 混沌石按引擎建模为「删 1 条 + 加 1 条」，非整件重 roll；
- 精华对魔法物品按「升级为稀有并追加指定词缀」处理；完美精华按「替换一条同位词缀」处理；
- 强效升华预兆（额外 +1 词缀）上游标记为未验证，界面上以「实验」标注；
- 价格种子估值仍保留在数据中但 UI 不再显示换算；
- 破溃宝珠要求稀有物品 ≥4 条词缀（与游戏一致）；
- 狂乱大锤（Fanatic Greathammer）的插画在 CDN 上缺失（403），该基底暂无图。
